# 💰 ExpenZo — Student Expense Tracker

> A simple and beginner-friendly web application for students to manage their income and expenses.

## 📌 About the Project

**ExpenZo** is a web-based expense tracking application developed as a **Project-Based Learning (PBL)** project.

The main purpose of ExpenZo is to help students keep track of their **income, expenses, available balance, and spending patterns** in one place.

The project is being developed using **HTML, CSS, and Vanilla JavaScript**, with a focus on learning practical web development, JavaScript, data handling, and collaborative GitHub development.

---

## 🎯 Objectives

* Track personal income and expenses.
* Calculate the available balance.
* Organize expenses into categories.
* Maintain transaction records.
* Provide useful spending information through analytics.
* Learn practical JavaScript development.
* Learn how to work collaboratively using Git and GitHub.

---

## 👨‍🎓 Target Users

The primary target users of ExpenZo are **students** who want a simple way to manage their day-to-day finances.

---

## ✨ Planned Features

### 💰 Income Management

* Add income manually.
* View income records.
* Edit income records.
* Delete income records.
* Support for recurring monthly income.

### 💸 Expense Management

* Add expenses.
* Categorize expenses.
* Add date and description.
* Select payment method.
* Edit expenses.
* Delete expenses.

### 🏠 Dashboard

* Total income.
* Total expenses.
* Available balance.
* Recent transactions.
* Quick access to important features.

### 📊 Analytics & Reports

* Income vs. expenses.
* Category-wise spending.
* Monthly spending information.
* Spending trends and visual reports.

### 💾 Data Management

* Store application data in the browser.
* Use JavaScript objects and JSON data.
* Use LocalStorage for persistent browser-side storage.
* Future support for exporting data as JSON.
